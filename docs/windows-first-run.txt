SOHO — предварительная проверка домашних работ

ПЕРВАЯ УСТАНОВКА

1. Установите ChatGPT Desktop и войдите в свой аккаунт
2. Распакуйте весь ZIP-архив, не запускайте программу прямо из архива
3. Откройте SOHO-Setup.exe, введите логин и пароль SOHO
4. Нажмите «Установить / обновить», затем «Проверить подключение»
5. Перезапустите ChatGPT Desktop
6. В новом диалоге выберите навык soho-homework-review через меню навыков
   В ChatGPT используется @, в Codex — $
7. Попросите показать очередь, затем выберите работу для проверки

Пример запроса после выбора навыка:
Проверь работу по ссылке [вставьте адрес чата SOHO] и подготовь отчёт для преподавателя

Для каждого другого ученика открывайте новый диалог
Оценку, комментарий и результат вы выставляете сами на сайте SOHO

ИЗМЕНЕНИЕ ПРАВИЛ

В меню «Пуск» → SOHO Review выберите «Изменить правила проверки»
Откроется используемый SKILL.md в Блокноте
Меняйте требования к проверке и формат отчёта, затем сохраните файл
Оставьте поля name и description в начале файла
Испытайте новые правила на уже проверенной вами работе в новом диалоге

ОБНОВЛЕНИЕ

Распакуйте новый комплект, закройте ChatGPT и откройте новый SOHO-Setup.exe
Оставьте логин и пароль пустыми, чтобы сохранить прежний доступ
Нажмите «Установить / обновить»
Изменённый вами SKILL.md и дополнительные настройки .env сохраняются
Резервные копии имеют суффикс .backup-...
После установки архив и распакованный комплект можно удалить

ГДЕ ХРАНЯТСЯ ФАЙЛЫ

Программа и .env: %LOCALAPPDATA%\SOHO Review
Правила: %USERPROFILE%\.agents\skills\soho-homework-review\SKILL.md
Материалы: %LOCALAPPDATA%\SOHO Review\materials
Подключение: %USERPROFILE%\.codex\config.toml
Если настроен CODEX_HOME, используется config.toml из этого каталога

Логин и пароль сохраняются локально в .env, не передавайте этот файл другим
В архиве для установки нет чужих паролей, HAR и ученических работ

ЕСЛИ НЕ РАБОТАЕТ

Закройте ChatGPT перед обновлением и проверьте подключение в окне настройки
В ChatGPT откройте Settings → MCP servers: подключение soho должно быть включено
Если оно ранее добавлено вручную, удалите его там и повторите установку
Если навыка нет в списке, перезапустите приложение и откройте новый диалог
Веб-версия ChatGPT не получает локальное подключение через эту установку

Проверка подключения подтверждает вход и работу инструментов MCP
Она не подтверждает качество проверки нейросетью или доступность каждой ссылки
Доски с JavaScript, входом или CAPTCHA могут остаться недоступны

Программа использует Windows PowerShell и Windows Forms, без Go и Python
Корпоративные ограничения запуска могут потребовать помощи администратора
