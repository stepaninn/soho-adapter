# Пакет Windows

## Передача брату

Сборка из корня репозитория:

```sh
go run ./cmd/package-windows
```

Готовый комплект — `dist/soho-windows-amd64.zip`. Передавайте только этот архив.
В нём три программы и `Первый запуск.txt`. Для Windows ARM64 доступен флаг
`--arch arm64`. На целевом компьютере не нужны Go, Git и Python

Брат распаковывает архив, открывает `SOHO-Setup.exe`, вводит свои данные SOHO,
нажимает «Установить / обновить» и «Проверить подключение». После этого
перезапускает ChatGPT Desktop и выбирает навык в новом диалоге

Установщик использует общий конфигурационный файл локального Codex-хоста,
который читает ChatGPT Desktop. Это не установка подключения для ChatGPT web
и не проверка доступности функций в конкретном аккаунте. Если подключение
отключено в приложении, включите его в Settings → MCP servers

## Пользовательские изменения

Рабочий файл правил находится в
`%USERPROFILE%\.agents\skills\soho-homework-review\SKILL.md`. Это обычный файл,
без символической ссылки. Ярлык «Правила проверки SOHO» на рабочем столе
сразу открывает именно его в Блокноте. Рабочий стол определяется средствами
Windows, включая перенаправление в OneDrive. Кнопка «Изменить правила проверки»
также доступна в окне настройки

Навык по умолчанию встроен в установщик из исходного `SKILL.md`, но копируется
только при первой установке. Обновление сохраняет пользовательскую методику
и делает резервную копию. Обновления исходного навыка не сливаются с правками
пользователя автоматически. Новый диалог нужен для проверки обновлённых правил

Настройки доступа лежат в `%LOCALAPPDATA%\SOHO Review\.env`. При обновлении
пустые поля логина и пароля сохраняют файл. При смене учётных данных остальные
строки `.env` сохраняются. Пароль передаётся дочернему процессу через stdin,
не через командную строку, и сохраняется локально в `.env` без шифрования

Подключение добавляется в `%USERPROFILE%\.codex\config.toml`, либо в
`CODEX_HOME/config.toml`, если переменная задана. Установщик владеет только
блоком между маркерами SOHO. TOML проверяется до изменения файлов, остальные
настройки сравниваются по значениям и сохраняются вместе с комментариями
Ручное подключение с именем `soho` не перезаписывается: окно предложит удалить
его в настройках приложения и повторить установку

Обновления отдельных файлов выполняются через временный файл и переименование,
с резервными копиями `.backup-...`. Установка целиком не является транзакцией:
при ошибке диска или занятом `.exe` повторите её после устранения причины
Перед обновлением закройте ChatGPT. При успешной установке исходный распакованный
комплект можно удалить: программы работают из постоянного пользовательского каталога

## Важные части реализации

- `internal/privatefs` — права `0700` в Unix и защищённый ACL в Windows
- `internal/desktopsetup` — установка, резервные копии, настройки MCP и сохранение skill
- `cmd/soho-setup` — окно Windows Forms через встроенный Windows PowerShell и backend на Go
- `cmd/package-windows` — кросс-сборка и ZIP только из явно перечисленных файлов
- `cmd/mcp-check --server` — проверка готового MCP без установленного Go

Windows ACL разрешает доступ текущему пользователю и SYSTEM, закрывая наследование
прав каталога. Временные файлы загрузки наследуют эти права. На файловой системе
без поддержки ACL установка завершится ошибкой. `ExecutionPolicy Bypass` применяется
только к процессу встроенного скрипта окна; системная политика не меняется

Добавлена зависимость `go-toml/v2`, чтобы проверять существующую конфигурацию,
а не пытаться разбирать произвольный TOML регулярными выражениями. `x/sys/windows`
уже был в зависимостях и теперь используется напрямую для ACL

## Проверка на Windows

Автоматизация находится в `.github/workflows/windows.yml`: обычные тесты,
проверка ACL, синтаксиса PowerShell, сборка и установка с искусственными данными
в отдельный временный профиль. Доступ к живому SOHO в CI не используется
Наличие workflow не означает, что он уже выполнялся

Перед передачей выполните ручную проверку на Windows 10/11:

1. Распакуйте комплект в путь с пробелами и кириллицей, установите его обычным пользователем
2. Проверьте окно, кнопки, ярлык правил на рабочем столе и три ярлыка в меню «Пуск»
3. Выполните проверку подключения с настоящими данными SOHO
4. Откройте новую проверку в Desktop: проверьте чтение PDF, изображения и ссылки
5. Откройте ярлык правил на рабочем столе, измените формат отчёта в skill, сохраните и испытайте в новом диалоге
6. Закройте ChatGPT и повторите установку с пустыми полями: правила и доступ должны сохраниться
7. Удалите распакованный комплект и откройте настройку через меню «Пуск»

Кросс-сборка из Linux не подтверждает работу окна, ярлыков, ACL и подключения
в конкретной Windows. Wine не заменяет такую проверку. Подключение MCP также
не подтверждает понимание PDF моделью: сравните отчёт с ручной проверкой работы
